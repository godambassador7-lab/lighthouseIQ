# LightkeeperIQ Education

LightkeeperIQ Education is a standalone marketplace-intelligence app for early-childhood care and education teams. It turns public WARN records into a focused view of employer disruption, affected workers, geography, and state-level market activity.

## Run locally

```powershell
npm run education:dev
```

Then open `http://localhost:3200`.

## Data scope

The app screens public WARN records using early-childhood employer and service keywords. Matches are directional and should be verified against the linked filing. The app does not claim that every affected worker is an educator or childcare worker.
