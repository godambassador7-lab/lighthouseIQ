Signal Controls

Filter the recruiter feed to the exact markets and profiles you want.

Region + State(s)
Use Region for broad geography, then multi-select one or more states. Search, Select All, and Clear All are built in.

Filter by specialty focus (for example ICU, OR, ED, Med-Surg) using the specialty multi-select.
Healthcare Org Keyword
Search employers by name with partial matches.
Since Date + Minimum Impact
Limit results to recent notices and stronger nursing-impact signals.
Max Results
Set a custom cap or leave blank to show all matching notices.
